# Report project status

Resolve document paths using [documents.md](../references/documents.md). This workflow is read-only. Inspect the authoritative project documentation and report discrepancies for follow-up.

1. Start with the summary at the top of `docs/BACKLOG.md`. Check it against the active ticket details. If the table is missing or stale, use the detailed ticket records and report the gap.
2. Read the relevant PRD, architecture, and ADRs for context. Use `docs/BACKLOG_ARCHIVE.md` to account for completed work. Search ticket headings and status fields first, then read specific entries as needed. Count cancelled tickets separately from completed work. Include `Done` and `Cancelled` tickets still in the active file and flag duplicate IDs without counting them twice.
3. Report current phases or epics, completed work, in-progress work, and remaining tickets. Include known blockers and their resumption conditions, documentation inconsistencies, and recommended next actions in priority order. Distinguish verified status from missing or conflicting evidence.
