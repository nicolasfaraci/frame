# Request an independent review

1. Identify the ticket or change, its base and exact target using [revisions.md](../references/revisions.md), and the acceptance criteria. Resolve any existing context documents using [documents.md](../references/documents.md); a one-off diff review does not require Frame documents. Use any target supplied after the command. If the target remains ambiguous, ask the user to identify it.
2. Follow the [Independent Reviewer rules](../references/roles.md). If the current session took no part in implementing or fixing the change, review directly here. Otherwise, this command authorizes an independent Reviewer assignment through an available, authorized native tool; follow the [assignment protocol](../references/missions.md). If this session is not independent and no independent execution is available, prepare a brief for a separate session and report the review as pending.
3. Return the verdict tied to the reviewed revision and the findings with severity, location, evidence, and remaining checks. The PO reprioritizes follow-ups and brings any required decision to the user. Apply backlog changes only within the user's authorized write scope and through the authorized writer. The command authorizes the review assignment. Fixes, additional assignments, integration, and ticket closure follow the standard rules.
